### 2. Backend Implementation

#### A. Database Migration for AI Comparisons
File: [supabase/migration_run2.sql](file:///c:/MY_Works/DepositGuard/supabase/migration_run2.sql)

```sql
create table if not exists public.ai_comparisons (
    id uuid default gen_random_uuid() primary key,
    inspection_id uuid references public.inspections(id) on delete cascade not null,
    move_in_item_id uuid references public.room_items(id) on delete set null,
    move_out_item_id uuid references public.room_items(id) on delete set null,
    item_name text not null,
    room_name text not null,
    change_type text not null check (change_type in ('none', 'normal_wear', 'possible_damage', 'unclear')),
    confidence numeric(4, 3) not null default 0.0,
    rationale text not null default '',
    ai_status text not null default 'success' check (ai_status in ('success', 'failed')),
    model_used text not null default 'gemini-3.8-flash',
    created_at timestamptz not null default timezone('utc', now())
);

alter table public.ai_comparisons enable row level security;

create policy "Members can view ai comparisons" on public.ai_comparisons
    for select using (
        exists (
            select 1 from public.inspections i
            join public.property_members pm on pm.property_id = i.property_id
            where i.id = ai_comparisons.inspection_id and pm.user_id = auth.uid()
        )
    );

create policy "Backend can insert ai comparisons" on public.ai_comparisons
    for insert with check (
        exists (
            select 1 from public.inspections i
            join public.property_members pm on pm.property_id = i.property_id
            where i.id = ai_comparisons.inspection_id and pm.user_id = auth.uid()
        )
    );
```

#### B. Gemini AI Service (Official SDK `google-genai`)
File: [backend/app/services/ai_service.py](file:///c:/MY_Works/DepositGuard/backend/app/services/ai_service.py)

- Uses `gemini-3.8-flash` (`GEMINI_MODEL_REASONING`) for GuardBot and before/after comparison.
- Uses `gemini-3.5-flash-lite` (`GEMINI_MODEL_FAST`) for note-to-JSON structuring.
- Grounded strictly in `RESEARCH NOTES/Research notes.txt` rules and Model Tenancy Act (MTA 2021) 2nd Schedule repair allocations.
- Pre-model validation (length 2-1000, letters check, mash rejection), per-user rate limit (20 req/min), 20s timeout, 1 retry with backoff on 429/503, and error codes (`invalid_input`, `rate_limited`, `timeout`, `upstream_unavailable`).
- Logs error code and latency only; never logs message content.

#### C. GuardBot Router
File: [backend/app/routers/guardbot.py](file:///c:/MY_Works/DepositGuard/backend/app/routers/guardbot.py)

- `POST /api/guardbot/chat`: Authenticated, non-streaming, with structured error mapping.
- `POST /api/guardbot/structure-note`: Fast note-to-JSON structuring with 1 retry and fallback to raw notes on second failure (`ai_status="failed"`).

#### D. Before/After AI Comparison Router
File: [backend/app/routers/comparison.py](file:///c:/MY_Works/DepositGuard/backend/app/routers/comparison.py)

- `POST /api/comparison/{move_out_inspection_id}`: Runs AI condition comparison against the **locked move-in record**. Caps photos at maximum 4 images per comparison. Saves results in `ai_comparisons` as advisory suggestions (never part of the locked hash; no liability or deduction amounts).
- `GET /api/comparison/{inspection_id}`: Fetches stored advisory comparison items.

#### E. Settlement & ReportLab PDF Export
Files: 
- [backend/app/routers/settlements.py](file:///c:/MY_Works/DepositGuard/backend/app/routers/settlements.py)
- [backend/app/services/pdf_service.py](file:///c:/MY_Works/DepositGuard/backend/app/services/pdf_service.py)

- ReportLab engine embeds:
  - Cryptographic canonical SHA-256 seal and lock timestamp.
  - Dual tenant & landlord approvals.
  - Room-by-room items with conditions and notes.
  - Append-only cryptographic amendment ledger.
  - Settlement summary with itemized deduction claims.
  - Clearly labeled AI suggestions ("Advisory Only — AI Suggestion").
  - Prominent legal disclaimer: *"tamper-evident, not tamper-proof; documentation, not legal advice"*.
